Build CMP gathers, then process all CMPs. Missing or under-folded bins remain blank.
Use Stack / Model TWT, or enable Flip-flop, to compare the unmigrated stack with the original model converted to vertical two-way time. Flat reflectors should approximately align. Dipping events generally will not: their common reflection/depth point is not the surface midpoint, so DMO/migration is required for proper positioning.
Teaching assumptions

2D variable-density acoustic simulation; simple hyperbolic NMO; no elastic modes, statics, DMO, migration, residual moveout, anisotropy correction, deconvolution, or sophisticated preprocessing. The output is an NMO CMP stack, not a fully processed seismic image.

Dipping reflection: CMP stacking alone does not fully correct dip. DMO/migration would be required.
