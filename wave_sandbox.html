Acquire shots to measure how amplitude decays down the record.
Left: the peak amplitude of the first arrival against offset, on log axes, where geometric spreading can be measured without reflectivity confusing it. Two reference slopes are drawn. r−0.50 is spreading alone: this is a 2D simulation, so the source is a line and the wavefront a cylinder, and energy spreads over 2πr rather than 4πr². r−1.50 adds the free-surface ghost — source and receivers sit a few metres down, and for a nearly horizontal path the delay to their surface images shrinks as 1/r, so the ghost pair cancels ever more completely with offset. The measured points follow the second, not the first.
Right: mean trace RMS down the record, before and after gain, with the trend each carries. Note that the raw record does not simply decay — it is loudest around the strongest reflector, not at the first break — which is why the reported number is the fitted slope from the first break rather than a drop from the peak.
So neither √t (2D spreading alone) nor t (the 3D convention) is the correct compensation for this geometry — which is the useful lesson: source and receiver depth are acquisition decisions that processing then has to live with. AGC sidesteps the question by normalising each window to the same level, which is why it makes weak deep events visible and why it destroys the relative amplitudes any amplitude interpretation depends on.
Gain multiplies signal and noise by the same number, so it does not improve signal-to-noise at any sample on the record. Turn the noise up and watch the deep part of the gained record get louder and no cleaner.

Time migration, stretched to depth

Depth migration

Stack all CMPs, then run both migrations. Each panel is in metres, so the true interfaces can be drawn on both.
Both panels carry the same gold interfaces and the same vertical axis, so the difference between them is the difference between the two methods and nothing else. The upper one is the ordinary time-migrated section stretched into depth with the velocity field — a re-plot, adding no information, purely so it can be compared. The lower one sums along eikonal traveltimes through that field instead of along a hyperbola built from one RMS number per output point. Watch the flanks: time migration cannot represent the velocity changing sideways, so it bends them off the gold line and gathers the deep energy into a lens under the crest; depth migration puts them where they belong.
The arcs above the shallowest reflector are migration aliasing, not noise in the data. The stack is sampled every 20 m while the image grid is 5 m, so the summation curve is under-sampled and its impulse response does not fully cancel. A wider aperture reaches steeper parts of that curve and imports more of it, which is why the default is 500 m rather than the 800 m the time migration uses — try 300 m and 1200 m to see the trade against how much of the deep flanks get illuminated.
Both migrate with the model's own velocity field — the same array the wave simulation propagates through. That makes these reference images showing what each method can recover when the velocity is right, not results obtainable from the recorded data alone. A real depth migration has to build that field first, and is only ever as good as it.
Teaching assumptions

2D variable-density acoustic simulation; simple hyperbolic NMO. Available processing, in sequence order: amplitude recovery (√t, t or AGC), predictive and spiking deconvolution, zero-phase bandpass, front-end mute, semblance and constant-velocity-stack velocity analysis, Dix inversion, NMO with stretch mute, parabolic Radon demultiple, CMP stack and post-stack Kirchhoff time migration.

Still absent: elastic modes (no shear, no ground roll, no converted waves), attenuation and Q, statics, DMO, pre-stack migration and anisotropy correction. Post-stack depth migration is now present, on the Final Section stage: it sums along eikonal traveltimes through the interval velocity field rather than along a hyperbola from one RMS number, which is what lets it image the anticline flanks that time migration bends into a lens. It migrates with the model's own velocity field, so it shows what depth imaging recovers when the velocity is right, not what could be obtained from the recorded data alone. Migration here is post-stack and uses the stacking velocities, so it inherits any error in them; its amplitude treatment applies obliquity only, without the rho filter or geometric spreading, so positions are meaningful and relative amplitudes are only indicative.

Two measured caveats worth knowing. Amplitude decay is steeper than either textbook law: first arrivals fall as about r−1.55, not the r−0.50 of 2D cylindrical spreading, because source and receivers sit under a free surface and their ghosts cancel harder with offset — so neither √t nor t is exactly right here, and the Gain panel plots the measurement against both. The Radon transform is the adjoint, not a least-squares inverse: events smear along curvature, so the demultiple discriminates rather than separates — on a marine gather it left a seabed primary intact while removing 45% of the first water-bottom multiple and 80% of the second.

Time migration assumes the velocity above an image point does not vary sideways, and structure breaks that. On the anticline preset the model RMS velocity at 0.51 s runs 2032 m/s under the flanks against 2598 m/s under the crest — 28% of lateral variation — so an output point beneath the crest sums flank energy that travelled far slower than the velocity it is using, and over-migrates it into a lens under the crest. The shallowest reflector, with almost no laterally varying overburden, images correctly; the deeper two do not. Scaling the migration velocity to 0.75× (about the flank-to-crest ratio) opens the lens back into arches, which is the diagnostic. On the flat preset, where there is no lateral variation, the same operator returns all reflectors cleanly.

The two migrations side by side, measured. Tracking each imaged interface against the true one on the anticline preset, in RMS metres of depth error against a 61 m wavelength: interface 1, time 21 m against depth 36 m; interface 2, time 58 m against depth 41 m; interface 3, time 82 m against depth 55 m. Depth migration is not uniformly better — at the shallowest interface, where there is almost nothing laterally varying above it, time migration is sharper, because its output is a direct re-plot of the stack while the depth image pays for an aperture-limited summation and its aliasing. What depth migration buys is that its error stays roughly flat with depth while the time migration's doubles, tracking the lateral velocity variation above each interface (12%, 22%, 28%).

CMP stacking alone does not correct dip — that is what the migration step is there to show. DMO would still be needed where conflicting dips share a midpoint.
